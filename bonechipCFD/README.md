# bonechipCFD

OpenFOAM simulation case for serpentine microfluidic channel used in honors thesis.

## Purpose
Steady-state laminar flow simulation to characterize:
- pressure drop
- velocity fields
- streamlines
- wall shear behavior

## Key Directories
- 0/ : initial conditions
- 500/ : final solved state
- constant/ : mesh + material properties
- system/ : solver settings
